# 小红书文字图 · 极简大字报

> 加载方式：本项目按路径引用这份规范（`个人自媒体/.agents/skills/xhs-text-cards/SKILL.md`），
> 不依赖技能目录发现。在别的项目里用它，把整个目录复制过去即可。
>
> 本技能只管"怎么把文字做成一套能发的图"。观点怎么提炼属于写作，本技能不负责。
> 本项目的物料红线在项目根 `AGENTS.md`，别在这里重述。

## 何时用 / 何时不用

用：

- 手上有成稿（md、语音转写、草稿），要做成一整套小红书图文笔记。
- 已有图文要改风格、补一张、换配色。
- 要判断某段文字该拆成几张、每张放多少字。

不用：

- 需要插画、实拍、产品图的封面 → 本技能只做纯文字版式。
- 公众号长图、抖音封面、朋友圈九宫格 → 尺寸与信息密度不同。
- 只想润色文案、不动图 → 直接改文字即可。

## 交付物约定

```
<笔记名>/                     例：小红书-Vibcoding/
  01-封面.png                 编号即上传顺序，首图是封面
  02-<栏目>.png
  ...
  发布文案.md                 标题备选 + 正文 + 标签
```

硬指标：**1080×1440（3:4）PNG**。小红书竖图标准比例，上传不裁切。

## 设计规范

风格名：极简大字报——暖白底、墨黑字、全图只有一抹朱红。

| 项 | 值 | 说明 |
| --- | --- | --- |
| 画布 | 1080×1440 | 3:4 |
| 底色 | `#FAF9F6` | 暖白，纯白在手机上发冷 |
| 主文字 | `#111114` | 墨黑，不用纯黑 `#000` |
| 次级文字 | `#696763` | 小注、副标题 |
| 强调色 | `#FF3B2F` | 朱红，**全图唯一彩色** |
| 细线 | `#DEDBD4` | 顶栏横线、封面分隔线 |
| 左右边距 | 100px | 版心宽 880px |
| 顶栏 | 编号 y=148，横线 y=218 | 所有内容卡固定，不随内容挪动 |
| 正文起点 | y=300 | 固定，保证 7 张之间文字对齐 |
| 页脚 | y=1384 | 左：系列名；右：`03 / 07` |

字号体系（改动只能在 `scripts/render_cards.py` 顶部常量里改，不要单张硬编码）：

| 用途 | 字号 / 字重 | 行高 |
| --- | --- | --- |
| 封面大标题 | 118 / Songti SC Black | 1.50 |
| 封面栏目 kicker | 31 / 字距 +3px / 朱红 | — |
| 封面副标题 | 38 / W3 / 次级色 | 1.78 |
| 内容卡标题 | 74 / W6 | 1.42 |
| 正文 | 56 / W3 | 1.74 |
| 小注（金句卡补充） | 46 / W3 / 次级色 | 1.80 |
| 金句卡大字 | 76 / W6 | 1.52 |
| 朱红金句 | 42 / W6 / 朱红 | — |
| 页脚 / 页码 | 26 / W3 | — |

## 字体

- 正文与标题：`/System/Library/Fonts/Hiragino Sans GB.ttc`，索引 `0`=W3、`2`=W6。
- 封面大字：`/System/Library/Fonts/Supplemental/Songti.ttc`，索引 `0`=Songti SC Black。宋体压黑体，才有"报纸社论"的分量感。
- 换机器或字体缺失时，先枚举 ttc 里的字面，别猜索引：

```bash
python3 -c "
from PIL import ImageFont
p='/System/Library/Fonts/Hiragino Sans GB.ttc'
[print(i, ImageFont.truetype(p,40,index=i).getname()) for i in range(4)]"
```

## 版面骨架（7 张的默认结构）

| 位置 | 卡片 | 职责 | 构成 |
| --- | --- | --- | --- |
| 1 | 封面 | 决定点击率 | kicker 栏目 + 两行大标题 + 两行副标题 + 分隔线 + "左滑读完全文 →" |
| 2–4 | 内容卡 | 铺陈：现象 → 身边案例 → 质疑 | 顶栏 + 标题 + 短墨线 + 1–3 段正文 |
| 中段 | 金句卡 | 转发点、截图点 | 76px 三行大字 + 朱红短线 + 一句小注 + 一句朱红金句 |
| 5–6 | 转折卡 | 类比、澄清、给方法 | 同内容卡 |
| 末 | 结论卡 | 收口，回到"那到底该怎么办" | 同内容卡，标题两行，末段用朱红强调 |

规矩：

- 张数 **6–8 张**。少于 6 张信息装不下，多于 8 张划不完。
- **一张卡只讲一件事**；单卡正文 ≤ 3 段、≤ 120 字。
- 金句卡放在情绪最高点（通常是原稿最尖锐的那句反问），不要放最后。
- 封面标题必须是"一句能让人停下来"的疑问或断言，不要写"关于 X 的思考"。

## 中文折行规则（返工最多的地方，逐条守）

1. 每行 **≤ 15 个全角字**（56px × 15 = 840px ≤ 版心 880px）。
2. **手动断行优先**：JSON 里用 `\n` 按语义断句，不要交给自动折行。自动只用于长段落。
3. 自动折行已内置：避头尾（句读不出现在行首、开引号不留在行尾）、引号内短句整体不拆、常用双字词不拆。
4. 孤字回拉只处理末行极短的情况；若它造成更差的断句（如"这不 / 现实"），**改成手动断行**。
5. 标点悬挂（行末句号超出 20px 内）可接受，超过 40px 改文案。
6. 每张卡最多 **1–2 处 `[[强调]]`**；强调只改颜色 + 字重，**不改字号**，否则行高错乱。

## 制作流程

1. 读原稿，抽出观点链：现象 → 案例 → 质问 → 类比 → 澄清 → 结论。链断了先补，再排版。
2. 复制 `examples/vibcoding.json` 改内容。字段：`series`、`cover{kicker,title,sub,foot}`、`cards[{num,label,title|big+big_text,blocks}]`。
3. 出图前先 lint，只看断行不落盘：

```bash
python3 .agents/skills/xhs-text-cards/scripts/render_cards.py \
  --input <内容.json> --lint
```

4. 出图：

```bash
python3 .agents/skills/xhs-text-cards/scripts/render_cards.py \
  --input <内容.json> --out <笔记名目录>
```

5. **逐张读图**（必须，见验收清单）。
6. 写 `发布文案.md`：3 个备选标题（≤20 字）+ 正文 + 8 个标签。

内容 JSON 的 block 类型：

| block | 含义 |
| --- | --- |
| `["p", "正文"]` | 56px 正文，支持 `[[...]]` 与 `\n` |
| `["p_small", "小注"]` | 46px 次级色 |
| `["sp", 30]` | 垂直留白（段间还自带 30px，通常不用手写） |
| `["accent_note", "一句话"]` | 42px 朱红金句 |

## 验收清单（缺一条不算做完）

- [ ] 全部文件 1080×1440，PNG：

```bash
python3 -c "
from PIL import Image; import glob
for f in sorted(glob.glob('<目录>/*.png')): print(f, Image.open(f).size)"
```

- [ ] **逐张打开看过**，不是只确认文件生成成功。看：断行是否断在词中间、有没有孤字行、强调色是否 ≤2 处、页脚编号是否连号。
- [ ] 内容包围盒在安全区内（防裁切/贴边）：

```bash
python3 -c "
from PIL import Image, ImageChops; import glob
BG=(250,249,246)
for f in sorted(glob.glob('<目录>/*.png')):
    im=Image.open(f).convert('RGB'); bg=Image.new('RGB',im.size,BG)
    l,t,r,b=ImageChops.difference(im,bg).getbbox()
    print(f.split('/')[-1], 'OK' if l>=60 and r<=1020 and b<=1400 else '检查', l,t,r,b)"
```

- [ ] 与原文对照：观点、口头语、比喻一个没漏，**语气没被改写成书面语**。
- [ ] `发布文案.md` 备好，标题 ≤20 字。

## 已知踩坑

| 现象 | 原因 | 改法 |
| --- | --- | --- |
| 每张卡标题高度不一样，翻页时文字跳动 | 曾用"整块垂直居中" | 顶栏与正文起点全部固定（148 / 300），让内容向下生长 |
| 宋体大字被红色下划线压住 | 下划线按字框顶算 | 下划线画在末行基线下方 172–190px |
| "根本 / 跟不上"被拆开 | 贪心折行不懂词 | 词表 `KEEP_TOGETHER` 里加词，或手动 `\n` |
| 加了字号后某张溢出 | 单卡字数过多 | 先 `--lint`，再看渲染时的"内容溢出"提示；溢出就拆卡或删字 |
| 引号里的话被拆到两行 | 逐字折行 | 已按 `「...」` 整体成 token 处理；超过 9 字仍会拆，需手动断行 |
